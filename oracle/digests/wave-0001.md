## ExtractIcon patch
- Wine's `ExtractIcon16` takes a `UINT16` index and passes it to `ExtractIconA`. `ExtractIconW` counts icons only for `(UINT)-1`, so 0xFFFF asks for icon 65535, gets NULL, and `convert_icon_to_16(NULL)` returns 0. [REF Wine 11.0 dlls/shell.dll16/shell.c, dlls/shell32/shell32_main.c]
- In Win16, index −1 returns the number of icons in the file. [REF Win16 SDK ExtractIcon]
- The patch hands 0xFFFF to `ExtractIconA` as `~0u` and returns the count without converting it to an icon. It adds 4 lines to `dlls/shell.dll16/shell.c`. [DESIGN]
- **Build:** `oracle/wine/build_patched.sh /opt/wine-11.0-oldwow /opt/wine-11.0-oldwow-patched shell16-extracticon-count.patch` (with `WINE_GIT` set to a local wine-11.0 clone). [ORACLE wave-0001]
  - Both Kron4ek builds ship the same `lib/wine/i386-windows/shell.dll16` (sha256 `12973352…ace5a8`). The patched module's sha256 is `83194182…592ba66`.
  - `diff -rq` against the stock copy lists only `shell.dll16`.
- **Result** (`wave-0001-newgame`): [ORACLE wave-0001]
  - The scenario's 32 `SHELL.EXTRACTICON` calls have the same paths, indices and results as the otvdm run `otvdm-skip` of [runtime-0001](runtime-0001.md): 1 for each single-icon exe, 3 for ECHO.EXE, 0 for `"\"`, `"S\"`, `"D\"` and `"R\"`.
  - The status line for `tools` reads "There are 4 icons in 2 files.".
  - The briefing, the icon column and the target display draw the fixtures' red square, green diamond and blue cross.
- `oracle/env.sh` makes this install the `ORACLE_WINE` default. Stock old WoW64 stays available for comparisons with digests made on it. [DESIGN]

## Relay filter
- **Default profile:** the exclude list also holds the wave frame loop: `USER.GETASYNCKEYSTATE`, `GDI.SELECTCLIPRGN` and `USER.PTINRECT`. [DESIGN]
  - The newgame scenario then writes a 28.5 MB trace (78 MB in newgame-0002). The wave adds 0.6 MB/s while only part of the status display is drawn. [ORACLE wave-0001]
  - Once the full status display is drawn (see HUD), the wave adds 5–8 MB/s. About 22 000 `SETPIXEL` calls per second come from INSPACE.EXE seg11:0x39cd and seg11:0x3cb7, plus `PATBLT`, `SELECTOBJECT`, `BITBLT`, `SETRECT`, `FRAMERECT` and the `GETWINDOWTASK`/`GETACTIVEWINDOW` checks. [ORACLE wave-0001]
- **`ORACLE_RELAY_PROFILE=wave`** (the wave.sh default) excludes those calls and `GETKEYSTATE` as well. The reference run grows by 0.05–0.2 MB/s in the wave. [ORACLE wave-0001]
- Wine prints only some 300 characters of the list in its `load_list` line, which is what `relay_digest.py` shows. The scenarios log the whole list in `steps.txt`. [ORACLE wave-0001]
- Keys still reach the trace as WM_KEYDOWN/WM_CHAR in the CallTo16 lines of the main window procedure (INSPACE.EXE seg2:0x0224). [ORACLE wave-0001]

## Abort and exit
- **ESC** and **Alt-X** open template `#00f4` (ISPACE.DLL seg10:0x442b) at 340,322, size 345×125, with Save & Exit, Exit and Cancel. [ORACLE wave-0001]
  - ESC asks "Do you want to exit from the current game back to the intro?". Alt-X asks "Are you sure you want to exit Inner Space?".
  - The dialog returns 0 for Cancel, 0x251 for Save & Exit and 1 for Exit.
- **Save & Exit** opens the save dialog. Save gives the same refusal, after which the game returns to the logo intro and the title screen. Cancel on the save dialog also returns to the intro (`wave-explore`). [ORACLE wave-0001]
- On the intro or the title screen, Alt-X shows the same dialog with Save & Exit greyed. Exit opens template `#031f` at 301,161, size 422×446: "We hope you enjoy your trial version of Inner Space. …", with text from ENG_LANG.DLL `#5000` 330, and the buttons Exit and Order... [ORACLE wave-0001]
- Exit there ends the process. The game writes `Full=1`, `Menu=0`, `IconWnd=1`, `VScale=0`, `SmWnd=0` and `SScale=0`, calls `KillTimer(main, 1)` (INSPACE.EXE seg6:0x1a3d) and destroys the main window (INSPACE.EXE seg2:0x0e49). [ORACLE wave-0001]

## Files, INI, sound, timers
- **Files:** the run writes only `C:\WINDOWS\INSPACE.INI`. `C:\INSPACE\GAMES` stays empty: there is no LASTGAME, since no wave ends, and no `.SAV`. [ORACLE wave-0001] The manual writes LASTGAME at the end of each wave. [MANUAL High Scores]
- **INI writes in the wave:** `StratAsk=10`, `Restore=ORACLE1`, `Restore=ORACLE2`, then the exit keys above. [ORACLE wave-0001]
- **Sound** (`SoundSystem=0`): [ORACLE wave-0001]
  - The game never loads WAVEMIX.DLL. The only MMSYSTEM call in the wave is `WAVEOUTGETNUMDEVS` at the ambulance (ISPACE.DLL seg8:0x5de4).
  - The abort frees and reloads `SOUNDS\SND_FX.DLL` and `SOUNDS\ENG_FX.DLL`, around `MIDIOUTSETVOLUME`/`WAVEOUTSETVOLUME(…, 0xffffffff)`.
- **Timers:** no `SetTimer`, `KillTimer` or `timeSetEvent` call occurs between wave start and exit, apart from the `KillTimer` above. [ORACLE wave-0001]
