## The landing's driver lookups
At the first tick of state 6, in the same millisecond as strings 2137 and 2138, ISPACE.DLL (DS 0x0427; code selector 0x040f, return offsets 0x5cda, 0x5d35, 0x5d70, 0x5de4, 0x5dfe, 0x5e56 and 0x5eb7, five bytes after the call sites ISPACE.DLL seg8:0x5cd5, seg8:0x5d6b and seg8:0x5eb2 of formats.md) runs these calls, in every visit of this trial run: [ORACLE core-0007]
1. `GETSYSTEMDIRECTORY`, then `GETPRIVATEPROFILESTRING("Boot.description", "display.drv", "Video Card", …, 0x5a, "C:\windows\system.ini")`, returning 10 (the default);
2. `GETPRIVATEPROFILESTRING("drivers", "Wave", "", …, 0x28, system.ini)`, returning 0;
3. `GETPRIVATEPROFILESTRING("drivers.desc", "", "Sound Card", …, 0x5a, "C:\windows\control.ini")`, returning 10;
4. `WAVEOUTGETNUMDEVS()` (6 under this Wine) and `WAVEOUTGETDEVCAPS(0, …, 0x30)` (0, success);
5. `GETPRIVATEPROFILESTRING("network.setup", "netcard", "", …, 0x28, "C:\windows\protocol.ini")` and `("netcard", "", "", …, 0x5a, "C:\windows\SYSTEM\network.inf")`, both 0.

These are the reads of ISPACE.DLL seg8:0x5c86 in [formats.md](../../docs/re/formats.md#winini-systemini-and-other-files). Wine's `system.ini` has no `[Boot.description]` and no `[drivers]` `Wave`, and there is no `control.ini`, so the defaults "Video Card" and "Sound Card" are what the game gets here: the labels of the two cards in [core-0003](core-0003.md)'s registered fly-in. The trial draws no fly-in, so this run shows the reads only. [ORACLE core-0007]
