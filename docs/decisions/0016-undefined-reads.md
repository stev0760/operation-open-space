# ADR 0016: Reads the original leaves undefined

- **Status:** Accepted (2026-11-08); the decision-2 site of seg15:0x2a08 in the Consequences (2026-11-09) is Proposed. [DESIGN]
- **Scope:** the sites where the original reads a value its bytes do not define on that path, or acts in a way a Win32 build cannot repeat: a stack local or buffer byte no path writes, a read or write outside the record, table or buffer it means, an operation that faults, a stack word whose residue another routine leaves, and two values the port reads at another moment than the original. The collision pair's orientation word has its own ruling ([ADR 0015](0015-collision-orientation.md)); the roster's class byte is [ADR 0014](0014-saved-games.md) decision 5 and the roster and save fallbacks are its decision 11; the mode-1 flame local is in [ADR 0013](0013-wave-drawing-and-input.md)'s Consequences. [DESIGN]

## Context
- **A Win16 frame starts with residue.** The prologues of these routines reserve their locals with `sub sp` and clear nothing, so a local that only some paths write holds whatever the deeper frames of earlier calls left at that address. Where the bytes show which instruction wrote the slot last on every path, the value is defined after all; the seam word of seg8:0x6f3c is such a case ([core.md](../re/core.md#shot-hit-test-seg80x3688-and-seg80x6f3c), Its value). [BYTES seg8:0x3692 seg8:0x6f46 seg8:0x29f4]
- **Locals no path writes.** The fragment count [bp−8] of seg12:0x274a for a `Detail` outside 0 … 3; the smoke threshold of seg7:0x5b68 and the debris puff's threshold of seg7:0x5d6a for such a `Detail`; the pod index of seg13:0x4a1d when no pod word is above 0; the heading of seg13:0xd6c for a mode its switch does not list; the nearest-gate index of seg16:0xb4e when no gate is nearer than 20000; the image slot and x offset of seg12:0x129e for a pool other than 6 and 11; the first byte of the visit monitor's wrap buffer, which seg16:0x2e3c measures a word with and never writes; the palette word [bp−0xa] of seg10:0x4412 and [bp−0x1a] of seg8:0x2cd8, which only their palette branches write and which their restores test also with DGROUP:0x920e = 0; and T[6] of the smoke mover, the word past its six-word table, which only the seg18-mode block writes. [BYTES seg12:0x2824-0x28c7 seg7:0x5b77-0x5bbb seg7:0x5d8e-0x5da5 seg13:0x4a1d seg13:0xd6c seg16:0xc19-0xc73 seg12:0x1336-0x1375 seg16:0x31b5-0x3257 seg10:0x44fb seg10:0x4602 seg8:0x310c seg8:0x33a1-0x33ad seg7:0x5e13-0x5e28 seg7:0x5f17]
  - The smoke mover's T[6] is drawn at counter 54 and blacked by the end square of the same call, which covers that draw at every `Size` ([world.md](../re/world.md#smoke-seg70x5b68-and-seg70x5e04)). [BYTES seg7:0x602f seg7:0x6037-0x606c]
  - A `Detail` outside 0 … 3 comes only from a hand-edited INSPACE.INI. [DESIGN]
  - ISPACE.DLL's quick colour map (seg5:0x2a73, [ispace.md](../re/ispace.md#ordinal-notes), 17) compares each own-ramp entry's id with every earlier entry's id slot, and the slots of the entries that took the scheme's nearest colour instead hold stale stack bytes; a stale byte equal to the new id skips that ramp's allocation. [BYTES ISPACE.DLL seg5:0x2aff-0x2b28]
- **Reads outside the storage.** The original reads a pool record, a weapon word or a ship record at whatever index it holds, so an index outside the allocation reads the next bytes of the block or of DGROUP; the visit dialogs read their 80-byte stack buffers past the string's NUL. The port stores these as typed arrays and cannot read past them. [DESIGN]
- **Locations the port holds under another name.** DGROUP:0x3450, which the pickup dissolve seg12:0x129e reads for a slot outside 0 … 100 just after it writes weapon 16 into the missile entry, is W(16)−4 = DGROUP:0x2f54 + 0x50·16 − 4, the image slot word of weapon 16 (DOUGHNUTS), −1 from seg10:0x1fb2 until seg10:0x533a assigns a slot. [BYTES seg12:0x1378-0x1395 seg10:0x2da8]
- **Writes outside the storage.** seg13:0x6716(−1) from a missile's turn writes now − 1 to DGROUP:0x708c, four bytes below ship record 0; no instruction names that address ([globals.md](../re/globals.md#global-table)). [BYTES seg13:0x673d seg13:0x6753]
- **Faults.** seg13:0x4eec(ship, v) divides by v + 1000 on its v < 1 path, which a v of −1000 makes 0, an INT 0 in the original. After a short read of MASTER.SHP, seg14:0x3eda frees the block but keeps its handle DGROUP:0x95a6 and the far pointer DGROUP:0x6e20, so its next call returns at once with a freed table and seg14:0x4074 frees the handle a second time. ## Decision
1. **A local no path writes takes a fixed value, named at its site.** The value is the one the defined paths around it imply: the count's own floor for the fragment count (2); the open gate for a smoke or debris threshold, so the puff takes a record as at `Detail` 3; no action where the consumer can skip it (no pod, no turn, no draw for the smoke's T[6], no palette to restore for seg10:0x4412 and seg8:0x2cd8); the first candidate for a search that found none (gate 0); 0 for the dissolve's slot and offset; and a space for the monitor's unwritten byte, the width a space has in the strings around it. Where every value gives the same screen, as for T[6], the port is exact; elsewhere the oracle comparison excludes the site until a run shows the original's value. [DESIGN]
2. **A read outside the storage reads zero.** A record read through an index outside the pool's records reads a zeroed scratch record, reset at each such access, and writes into it are lost; a table word, a ship record or a buffer byte outside its storage reads 0 or NUL. Zero is what the original's zero-filled blocks and BSS hold most often, and no port path depends on the neighbour's value. Each guard logs once per session through the todo facility, so a run that reaches one shows it. [DESIGN]
3. **A DGROUP location keeps its identity.** A location that is a field the port holds under another name is read and written through that field: the pickup dissolve's DGROUP:0x3450 is weapon 16's image slot word W(16)−4. A write to a location the port does not hold, which no instruction reads by its address, is dropped: the turn's DGROUP:0x708c. [DESIGN] [BYTES seg12:0x1392 seg10:0x2da8 seg13:0x6753]
4. **An operation that faults in the original is skipped, and its operands keep their values.** The port does not reproduce a divide trap or a double free: seg13:0x4eec with v = −1000 leaves ship word +0x82 as it was, and a short read of MASTER.SHP leaves no table loaded (handle 0), as a failed open does. [DESIGN]
5. **A stack word whose residue the bytes determine is computed.** Where the bytes fix the last writer of the slot on every path the port runs, the port computes that value instead of holding a constant: the seam word of seg8:0x6f3c is the low word of the last barrel's y offset from the player's y at the last recentre, or 0x2b4f after the y wrap, and lo16(|DGROUP:0x88cc|) in seg18 mode ([core.md](../re/core.md#shot-hit-test-seg80x3688-and-seg80x6f3c)). A residue the bytes do not determine stays with decision 1 or its own ADR (ADR 0015). [DESIGN] [BYTES seg8:0x2ade seg8:0x2b4a seg8:0x2b95]
6. **A value read at another moment is allowed when it is provably equal on every path the original takes.** The site states the argument: the collisions' DGROUP:0x90f4 is held at 1 because collisions run only in state 1's frame; the debriefing's page text is built at the wave end because none of the words it reads changes before the first state-2 frame. [DESIGN]
7. **Every site cites this ADR** with its decision number in a `[DESIGN]` tag at the comment, so a later reading of the original's residue can find each place to change. [DESIGN]

## Alternatives
| Alternative | Verdict |
|---|---|
| Emulate a 16-bit stack and DGROUP layout so the residues come out as in the original | Rejected. The deeper frames that leave a residue are not known for most sites, and the port has no 16-bit stack; the cost is a second machine for values no player sees. [DESIGN] |
| Random or poison values at the unset sites | Rejected. They make runs irreproducible and hide the site; the port's runs must repeat bit for bit from the same seeds ([rng.md](../re/rng.md#reproducing-sequences)). [DESIGN] |
| Abort on a read outside the storage | Rejected. The original goes on with neighbouring bytes; a crash would be worse than any value. [DESIGN] |
| Reproduce the faults (a trap dialog, a double free) | Rejected. A Win32 divide fault ends the process and a double free corrupts the heap; the original's player saw a General Protection Fault box, not a game. [DESIGN] |
| Hold the seam word at 1 | Rejected as a ruling: the bytes give its value. The held 1 differs from the bytes only for a shot whose last head is level with the player's y at the last recentre, where the original skips the seam fix. [DESIGN] |
