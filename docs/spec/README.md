# Behaviour spec

Each file below will specify one subsystem from the manual, the oracle digests and the original's bytes. A file is added when its milestone writes it; until then the behaviour is in [`docs/re/`](../re/) and the oracle digests. Feature status lives in [checklist.md](checklist.md), whose area codes the list gives. [DESIGN]

- `input.md`: key bindings, accelerators, mouse and joystick (KEY).
- `windows.md`: main window, status display, dialogs, menus, intro and briefing screens (WIN).
- `navigation.md`: drive and directory walk, the Navigation window, waves and gates (NAV).
- `flight.md`: flight model, collisions and the game-time base (FLT).
- `weapons.md`: the gun and every weapon system (WPN).
- `hazards.md`: rocks, viruses, blocks and the other hazard objects (HAZ).
- `ship-systems.md`: damage, auto-repair, cloak, shield, wings, perspective shift and powerups (SHIP).
- `teams.md`: the eight teams, attitudes and relations (TEAM).
- `laws.md`: crimes, Enforcers, arrest and the Hall of Justice (LAW).
- `economy.md`: ambulance, credit, icon capture and fuel (ECO).
- `ai.md`: computer pilots, ship commands and defenders (AI).
- `racing.md`: race tracks, race records and duels (RACE).
- `inner-demon.md`: the black hole, the Noble Weapons and Demon's Gate (DMN).
- `settings.md`: the Game Settings, Audio, Display and Joystick dialogs (SET).
- `ini.md`: every INI key with its default and the module that reads it (INI).
- `audio.md`: sound effects, voices, mixing and music (SND).
- `factory.md`: the Ship Factory and the Enhanced Ship Factory (FAC).
- `screensaver.md`: INSPACE.SCR, INRUN.AD and the screen-saver demos (SCR).
- `modes.md`: Action and Strategy modes, the demo, saving and scoring, special times of day (MODE).
- `system.md`: install, calibration, registration and copy protection, help (SYS).
