# INSTALL.EXE: the sold installer

This page covers INSTALL.EXE, the installer of the v1.29.08 ship disk: its start-up, the validation of the install set, INSTALL.INI, its dialogs, the file copy, the registration call and the free v1.29.07 installer it differs from. Every address carries its module name. The records that ISPACE.DLL reads and writes for the installer are in [formats.md](formats.md#resources-rewritten-in-place), ordinal 24 in [ispace.md](ispace.md#ordinal-notes) and what the running installer showed in [install-0001](../../oracle/digests/install-0001.md). [DESIGN]

## Module
- INSTALL.EXE is the NE module `I_INSTALL` ("IS Installer"), packed by OPTLOADER: seg1 is the loader stub and seg2–seg4 are packed. seg2 and seg3 are code and seg4 is DGROUP. [BYTES INSTALL.EXE NE header]
- It imports from KERNEL, USER, GDI, LZEXPAND and DDEML. [BYTES INSTALL.EXE NE header]
- Its 14 resources are ICON 1, GROUP_ICON GAME, #5500 110 (32 bytes) and #5500 120 (128 bytes), RCDATA DLGINCLUDE and DIALOG 135, 300, 100, 1922, 1774, 891, 200, 175 and 333. Both #5500 records are all zero in the ship disk. [BYTES INSTALL.EXE resource table] [BYTES INSTALL.EXE 5500 110] [BYTES INSTALL.EXE 5500 120]

## Start-up
1. WinMain INSTALL.EXE seg2:0x0 parses the command line and then zeroes the FORCE flag INSTALL.EXE DGROUP:0x13f4 and the RELEASE flag INSTALL.EXE DGROUP:0x1400, so the INSTALL FORCE and INSTALL RELEASE paths never run ([Dead paths](#dead-paths)). [BYTES INSTALL.EXE seg2:0x38 seg2:0x3b]
2. Init INSTALL.EXE seg2:0x3b38 sets the source directory INSTALL.EXE DGROUP:0x1426 to the module path cut after its last backslash, with the first letter upper-cased. It sets INSTALL.EXE DGROUP:0x7ba = 1 and INSTALL.EXE DGROUP:0x15b4 = 1 unconditionally, and the INI path INSTALL.EXE DGROUP:0x1520 = source + "INSTALL.INI". [BYTES INSTALL.EXE seg2:0x3c52 seg2:0x3c6c seg2:0x3c77 seg2:0x3cbe]
3. It runs the version check INSTALL.EXE seg2:0x4a92 ([Validation](#validation)) and shows MessageBox("Make sure any running programs, (especially email programs) are exited before continuing.", "IS Install", 0x30). [BYTES INSTALL.EXE seg2:0x3d19 seg2:0x3d2e DGROUP:0x7ef DGROUP:0x10]
4. It runs the write test INSTALL.EXE seg2:0x3896 and the installed-before rule INSTALL.EXE seg2:0x27da. [BYTES INSTALL.EXE seg2:0x3d3f seg2:0x3d5f] The oracle shows the same order. [ORACLE install-0001]
5. INSTALL.EXE seg2:0x27da then calls INSTALL.EXE seg2:0xf5a(1), the first phase. It opens the "Installing..." dialog 200 and copies group [7] (INSPACE.INI, destination 0) into INSTALL.EXE DGROUP:0x1100, which holds the Windows directory at this point. The copy is skipped when the keep flag INSTALL.EXE DGROUP:0x13ec is set. [BYTES INSTALL.EXE seg2:0x2935 seg2:0x1b11]
6. With INSTALL.EXE DGROUP:0x4e = 1, INSTALL.EXE seg2:0x100e(0) then writes INSPACE.INI [Inner Space] `LocalPath`, `Path` and `ShipPath` = the Windows directory and `SndPath` = the source directory, and SYSTEM.INI [drivers] `MSACM.imaadpcm` = `imaadpcm.acm`. It loads ISPACE.DLL from the source directory (INSTALL.EXE seg2:0x3e1a), calls ordinal 4 command 0 (INSTALL.EXE seg2:0x4098), runs the validation INSTALL.EXE seg2:0x448a and draws the splash INSTALL.EXE seg2:0x2624(1, 1). [BYTES INSTALL.EXE seg2:0x1351 seg2:0x13bb seg2:0x13c0 seg2:0x13d9 seg2:0x13de seg2:0x13e8] [ORACLE install-0001]
7. After dialog 300 returns 1, the main window's message 0x7e8 (INSTALL.EXE seg2:0x175) calls INSTALL.EXE seg2:0xf5a(0), the second phase ([Dialogs](#dialogs), **Directory and screen saver**). [BYTES INSTALL.EXE seg2:0x175 seg2:0xf5a]

## Validation
- **Version.** INSTALL.EXE seg2:0x4a92 reads only INSTALL.INI [Vers] `V`, with GetPrivateProfileString("Vers", "V", "", buf, 10). It turns the first five digits into a number with the weights 10000, 1000, 100, 10 and 1 ("12908" gives 12908) and writes them into positions 1, 3, 4, 6 and 7 of "V0.00.00" in INSTALL.EXE DGROUP:0x7bc ("V1.29.08") for the splash. A result of 0 makes the init fail, and the installer exits with no message. [BYTES INSTALL.EXE seg2:0x4af2 seg2:0x4b0e seg2:0x4b3f seg2:0x3d28 DGROUP:0xc59 DGROUP:0xc5e]
  - INSTALL.EXE's DGROUP holds no "Def" and no "Limited" string, so the `Def=1` of the ship disk's INSTALL.INI is never read. [BYTES INSTALL.EXE seg2:0x4a92] [BYTES INSTALL.INI]
- **Write test.** INSTALL.EXE seg2:0x3896 calls LZOpenFile(source + "SECURE.DAT", OF_CREATE 0x1000), which creates or truncates SECURE.DAT in the source directory. On −1 it shows "Installer cannot run if install disk is write-protected. \nClose write-protect tab on back of disk and run install again." (0x30, "IS Install") and quits. SECURE.DAT has no other use. [BYTES INSTALL.EXE seg2:0x38cc seg2:0x3d4c DGROUP:0x77c DGROUP:0x849]
- **Installed before.** INSTALL.EXE seg2:0x27da sets INSTALL.EXE DGROUP:0x1100 = the Windows directory + `\`. When <Windows directory>\INSPACE.INI exists (OpenFile OF_EXIST), it reads [Inner Space] `SoundFX`, `VoiceFX` and `Music` (GetPrivateProfileInt, default 0) into INSTALL.EXE DGROUP:0x13fa, INSTALL.EXE DGROUP:0x13fc and INSTALL.EXE DGROUP:0x13fe and copies INSPACE.INI to <Windows directory>\INSPACE.BAK (INSTALL.EXE seg2:0x3868). [BYTES INSTALL.EXE seg2:0x27da seg2:0x289e seg2:0x28b6 seg2:0x2904]
  - It then asks "Inner Space has been installed before. Should old preferences be kept? (Answer No if installing to fix a problem)" ("IS Install", 0x124: MB_YESNO, MB_ICONQUESTION and MB_DEFBUTTON2, so No is the default). Yes (6) sets the keep flags INSTALL.EXE DGROUP:0x13ec = INSTALL.EXE DGROUP:0x13ee = 1. The box appears exactly when the Windows directory already holds INSPACE.INI. [BYTES INSTALL.EXE seg2:0x2918 seg2:0x291b seg2:0x292c DGROUP:0x6b2]
- **ISPACE.DLL.** INSTALL.EXE seg2:0x3e1a opens source + "ISPACE.DLL" with OF_EXIST and loads it with LoadLibrary. It takes ordinals 2, 1, 3, 4, 35, 7, 9, 10 and 24 by GetProcAddress into INSTALL.EXE DGROUP:0x13d0, 0x13c8, 0x13cc, 0x13d4, 0x13e8, 0x13d8, 0x13dc, 0x13e0 and 0x13e4. A missing file shows "Can't find ISPACE.DLL!!", a handle below 32 "ISPACE.DLL is faulty!!" and a null procedure "Library file ISPACE.DLL is corrupted!", each with 0x30 and "IS Install". [BYTES INSTALL.EXE seg2:0x3e79 seg2:0x3e9d seg2:0x3ebd seg2:0x3fcd DGROUP:0x8cf DGROUP:0x8e7 DGROUP:0x8fe]
- **Install set.** On the normal path INSTALL.EXE seg2:0x448a calls ordinal 24 command 1 with a = a copy of the source directory and b = INSTALL.EXE DGROUP:0x1100. ISPACE.DLL answers from the source INSTALL.EXE's #5500 120 and #5500 110 ([formats.md](formats.md#resources-rewritten-in-place)): bit 0 of the result goes to INSTALL.EXE DGROUP:0x15b2, and the message text INSTALL.EXE DGROUP:0x15d8 = "DRIVE " + b[0] + " [" + a + "]". [BYTES INSTALL.EXE seg2:0x45cb seg2:0x45d5] [BYTES ISPACE.DLL seg10:0x5416]
  - An empty b sets INSTALL.EXE DGROUP:0x1100 = "C:\SPACE\" and INSTALL.EXE DGROUP:0x7b6 = 0; any other b sets INSTALL.EXE DGROUP:0x7b6 = 1. [BYTES INSTALL.EXE seg2:0x462d seg2:0x4641]
  - Then come ordinal 24 command 3, INSTALL.EXE DGROUP:0x15b6 = 1 and INSTALL.EXE DGROUP:0x15d0 = INSTALL.EXE DGROUP:0x15d4 = INSTALL.EXE DGROUP:0x15ce = 0. INSTALL.EXE DGROUP:0x15ce becomes 1 when INSTALL.EXE DGROUP:0x7b6 ≠ 0, and INSTALL.EXE DGROUP:0x15b4 takes INSTALL.EXE DGROUP:0x15b6 (1) only when it is already non-zero. [BYTES INSTALL.EXE seg2:0x4659 seg2:0x4667 seg2:0x468d]
  - Only with INSTALL.EXE DGROUP:0x7b6 = 1 and bit 3 set does it clear INSTALL.EXE DGROUP:0x15b2 and INSTALL.EXE DGROUP:0x15b4 and ask "Inner Space validly installed … to DRIVE <b[0]> [<a>], which is not currently connected or has been altered. Reconnect drive for valid reinstall or deinstall. \n \n Do you wish to proceed and install a demo copy?" (0x134, "IS Install"). No (7) calls INSTALL.EXE seg2:0x3376 and DestroyWindow. INSTALL.EXE DGROUP:0x7b8 = 1 at the end. [BYTES INSTALL.EXE seg2:0x46af seg2:0x470e]
  - With the ship disk's all-zero records ISPACE.DLL returns 0 and b = "", so INSTALL.EXE DGROUP:0x1100 = "C:\SPACE\", INSTALL.EXE DGROUP:0x7b6 = 0 and INSTALL.EXE DGROUP:0x15b4 stays 1: a new valid install. [BYTES INSTALL.EXE 5500 110] [BYTES INSTALL.EXE 5500 120] [ORACLE install-0001]
  - The writer behind ordinal 24 commands 0, 4–8, 12, 13, 15 and 18 does nothing off drives A: and B: ([ispace.md](ispace.md#ordinal-notes), ordinal 24), so an install from a hard-disk copy never changes the source INSTALL.EXE and the same set validates and registers on every install. [BYTES ISPACE.DLL seg10:0x5612 seg10:0x562e]

## INSTALL.INI
- **Groups.** Sections [0] … [7] are file groups. Each key is a file name, taken by enumerating GetPrivateProfileString(section, NULL) (INSTALL.EXE seg2:0x14ec), and its integer value is a destination code (GetPrivateProfileInt, INSTALL.EXE seg2:0x1482). Files are copied group by group, 0 to 7, in key order. [BYTES INSTALL.EXE seg2:0x1482 seg2:0x14ec]
- **Destinations.** INSTALL.EXE seg2:0x1950 maps the codes: [BYTES INSTALL.EXE seg2:0x1950 seg2:0x19ab seg2:0x1a18 seg2:0x1a3d seg2:0x1a62 seg2:0x1b6c] [ORACLE install-0001]

  | Code | Target directory |
  |---|---|
  | 0 | the install directory INSTALL.EXE DGROUP:0x1100, as it stands |
  | 1–7 | the install directory + the n-th key name of [Dirs] (1 SHIPS, 2 SOUNDS, 3 GAMES, 4 RETIRED) + `\` |
  | 8 | the Windows directory + `\`; while the screen-saver answer INSTALL.EXE DGROUP:0x50 is 1, each code-8 file also writes SYSTEM.INI [boot] `SCRNSAVE.EXE` = <Windows directory>\INSPACE.SCR |
  | 9 | AD_PREFS.INI [After Dark] `Path` (default ""), or the Windows directory when that is empty, + `\` |

- **Group flags.** On OK of dialog 300, INSTALL.EXE seg2:0xdd6 clears the flags INSTALL.EXE DGROUP:0x1290[0 … 7] and sets [0] always, [1] for Inner Space (control 119), [2] Ship Factory (124), [3] Sound Effects (125), [4] Voice Effects (135), [5] Music Soundtrack (306) and [6] Screen Savers (304). Group [7] is set only for the first phase (INSTALL.EXE seg2:0x280e). [BYTES INSTALL.EXE seg2:0xe7d seg2:0xe91 seg2:0xea5 seg2:0xeba seg2:0xece seg2:0xee3 seg2:0xef8 seg2:0x280e]
- **The ship disk's INI.** [Vers] holds `V=12908` and `Def=1`; [Dirs] lists SHIPS, SOUNDS, GAMES and RETIRED; and a [Temp] section that INSTALL.EXE does not read follows the groups. [BYTES INSTALL.INI]

  | Group | Box | Files and codes |
  |---|---|---|
  | 0 | always | MASTER.BOD 1, MASTER.SHP 1, WAVEMIX.DLL 8, WAVEMIX.INI 8, CTL3D.DLL 8 |
  | 1 | Inner Space | ISPACE.DLL, ENG_LANG.DLL, IGRAPHIC.DLL, INSPACE.EXE, INSTALL.EXE, ENG_HELP.HLP, README.TXT, ORDER.TXT, all 0 |
  | 2 | Ship Factory | FACTORY.EXE 0 |
  | 3 | Sound Effects | SND_FX.DLL 2 |
  | 4 | Voice Effects | ENG_FX.DLL 2 |
  | 5 | Music Soundtrack | MAIN.MID, RACE.MID, DEMON.MID, ANTHEM.MID, all 2 |
  | 6 | Screen Savers | INSPACE.SCR 8, INRUN.AD 9 |
  | 7 | first phase | INSPACE.INI 0 |

- **Source names.** For key K, INSTALL.EXE seg2:0x36c2 probes K with its last character replaced by '1' (OpenFile OF_EXIST). A hit makes that name the source and sets INSTALL.EXE DGROUP:0x1594 = 1 (read through LZOpenFile and LZRead); a miss sets 0x1594 = 0. It then always probes K with the last character replaced by '_'; a hit makes that name the source but leaves 0x1594 as the '1' probe set it. With neither, the source is K itself. [BYTES INSTALL.EXE seg2:0x36f4 seg2:0x371f seg2:0x3747 seg2:0x378a]
  - When INSTALL.EXE DGROUP:0x1594 = 0, or in backup mode (INSTALL.EXE DGROUP:0x141e ≠ 0), the source opens with OpenFile(OF_READ) and is read with _lread; otherwise with LZOpenFile(OF_READ). INSPACE.ex_ and FACTORY.ex_ are plain MZ files, so they are copied raw. Name matching is case-insensitive (the ship disk has eng_fx.dll and ISPACE.dll). [BYTES INSTALL.EXE seg2:0x379b seg2:0x37ae] [BYTES INSPACE.ex_] [BYTES FACTORY.ex_] [ORACLE install-0001]
  - So a set holding both K1 and K_ would read K_ through LZ; the ship disk has no such pair. [BYTES INSTALL.EXE seg2:0x3747] [BYTES INSTALL.INI]
- **Targets.** The target is the target directory + K, opened with LZOpenFile(OF_CREATE 0x1000); outside backup mode INSTALL.EXE becomes BACKUP.EXE (INSTALL.EXE seg2:0x1b25). INSTALL.EXE seg2:0x37be copies one 0x800-byte chunk per call (LZRead or _lread, then _lwrite) and closes both handles with LZClose after a short read. No file date is set, so the installed files carry the copy time. [BYTES INSTALL.EXE seg2:0x1b25 seg2:0x37be seg2:0x380e seg2:0x3825] [ORACLE install-0001]
- **Skips** (INSTALL.EXE seg2:0x1950, flag INSTALL.EXE DGROUP:0x13f8). Outside backup mode and with keep-prefs INSTALL.EXE DGROUP:0x13ee set, group 0 keys 0 and 1 (MASTER.BOD and MASTER.SHP) are checked against their target with OF_EXIST. An existing target is skipped (0x13f8 = 1, return before INSTALL.EXE seg2:0x36c2); a missing one clears INSTALL.EXE DGROUP:0x13ee, so every later keep check copies. Group 7 key 0 (INSPACE.INI) is skipped when INSTALL.EXE DGROUP:0x13ec is set: 0x13f8 = 1, INSTALL.EXE seg2:0x36c2 opens nothing and INSTALL.EXE seg2:0x37be reports the file done and clears 0x13f8. [BYTES INSTALL.EXE seg2:0x1aa9 seg2:0x1aed seg2:0x1b03 seg2:0x1b18]

[BYTES INSTALL.EXE seg2:0xb6a seg2:0xc44 seg2:0xd1d DGROUP:0x213] [ORACLE install-0001]

- **Path on OK.** INSTALL.EXE seg2:0xdd6 reads edit 301 with GetWindowText(…, 0x6e) into INSTALL.EXE DGROUP:0x1100. A one-character text gets ':', and a missing trailing `\` is added. [BYTES INSTALL.EXE seg2:0xe09 seg2:0xe2a]
  - INSTALL.EXE seg2:0x38ee strips the backslash, saves the current directory and does chdir(p). When that fails it does mkdir(p) (failure: invalid) and chdir(p) again, and a second failure does rmdir(p) and reports invalid. After a successful chdir it calls _getdcwd(drive), changes back and calls rmdir(p), which also removes an existing empty directory, then compares p with the _getdcwd result (lstrcmp). The path is valid when they are equal. [BYTES INSTALL.EXE seg2:0x3952 seg2:0x3961 seg2:0x3995 seg2:0x39ad seg2:0x39be]
  - An invalid path shows MessageBox(hDlg, "The install path you typed in is too long or invalid. \nMake sure directory names are 8 characters long or shorter and do not include spaces.", "IS Install", 0x10) and keeps the dialog. Cancel (IDCANCEL) ends it with 0, and the main window then posts 0x7f2, which runs INSTALL.EXE seg2:0x3376 and DestroyWindow. [BYTES INSTALL.EXE seg2:0xe5c seg2:0xe6c DGROUP:0x21b]

[BYTES INSTALL.EXE seg2:0x1c75 seg2:0xf7e seg2:0x175] [ORACLE install-0001]

- **Dialog 135.** The init sets edit 2 to "name" and edit 3 to "organization", limits them to 0x14 and 0x19 characters (EM_LIMITTEXT), selects all of Name and focuses it. [BYTES INSTALL.EXE seg2:0x2964 seg2:0x2997 DGROUP:0x724 DGROUP:0x729]

- **Speed test.** INSTALL.EXE seg2:0x2b53 counts GetCurrentTime polls in a busy loop for 1000 ms and writes [Inner Space] `Detail` = 3 when the count is above 350000 (0x55730), 2 above 180000 (0x2bf20), 1 above 70000 (0x11170) and 0 otherwise (unsigned, strictly greater).
