# The shell: start-up, screens and exit

This page covers the shell of INSPACE.EXE: start-up up to the first idle frame, the exit paths, the screen states and their transitions, the intro and title screen, the dialogs that start a game, the main window's geometry, the game palette and the help paths. Addresses without a module name are in INSPACE.EXE, whose DGROUP is seg19. The message loop and frame pacing are in [timing.md](timing.md), WndProc, the WM_COMMAND handler and the game tick in [globals.md](globals.md), INI keys and their defaults in [formats.md](formats.md#ini-files), the ISPACE.DLL ordinals in [ispace.md](ispace.md) and what the running original showed in [oracle.md](oracle.md). ## Start-up
WinMain (seg2:0x0) and the start-up routine seg6:0x12b6 run in this order:

1. WinMain copies "Inner Space" (DGROUP:0x82) to DGROUP:0x9690 as the class and application name, and the command line to DGROUP:0x1d60. It calls SetCursorPos(SM_CXSCREEN / 2, SM_CYSCREEN): only x is halved, so the cursor goes to the bottom centre. It saves GetCursorPos in DGROUP:0x1d48. [BYTES seg2:0x10-0x55 seg2:0x37-0x4c seg2:0x55]
2. It uppercases the command line in DGROUP:0x1d60 in place with seg11:0x3fd4(DGROUP:0x1d60, 1) before anything reads it. Mode 1 turns a–z into A–Z except the character right after a `(`. WinMain never reads nCmdShow. It calls seg6:0x12b6 as a Pascal function of (hInstance, hPrevInstance, a 26-byte WNDCLASS passed by value) that returns with `retf 0x1e`. [BYTES seg2:0x2f seg11:0x3ffa seg11:0x400c seg11:0x40d4 seg11:0x40da seg2:0x5a seg2:0x5e seg2:0x6b seg2:0x6d seg6:0x17db]
3. **Single instance.** The test uses hPrevInstance only. GetInstanceData copies the previous instance's DGROUP:0x16. When IsWindow accepts it, the new instance runs seg6:0x1c0c (which posts 0x9f0 or 0x9fa to that window for its own command line), posts WM_SYSCOMMAND SC_MAXIMIZE to it and quits without a message. Otherwise it shows MessageBox(NULL, "Another version of game already running." (DGROUP:0x4a0), "Inner Space", MB_ICONEXCLAMATION) and quits.
